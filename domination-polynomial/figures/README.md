# Figures

All figures use Inter and sentence-case labels. PNGs are exported at 600 dpi;
SVG and PDF versions preserve vector detail.

- `graph_example.svg` / `.png` / `.pdf`: every vertex and edge of the
  182-vertex projective example, alongside the 14-vertex toy with a verified
  dominating set. Both are illustrations, not certified counterexamples.
- `canonical_certified_valley.svg` / `.png` / `.pdf`: certified interval-mass and
  coefficient bounds for the actual Lean-verified canonical counterexample.
  This is an inequality diagram, not a computed coefficient curve.
- `toy_exact_coefficients.svg` / `.png` / `.pdf`: exact coefficients of the 14-vertex
  illustrative gadget. It is unimodal and is not a counterexample.

The sources, exact data, interpretation, and reproduction commands are in
[the examples directory](../examples/README.md).
