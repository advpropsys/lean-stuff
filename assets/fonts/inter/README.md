# Inter

These unmodified Inter Regular and Bold font files identify themselves as
version 3.019 (`git-0a5106e0b`), copyright 2020 The Inter Project Authors.
They are distributed under the included [SIL Open Font License](https://github.com/advpropsys/lean-stuff/blob/main/assets/fonts/inter/OFL.txt).

Upstream: [Inter](https://github.com/rsms/inter/releases/tag/v3.19).
The license is copied from the matching upstream release tag.

The plotting scripts register these files directly. No system font installation
is required. Text and mathematical labels use Inter; SVG exports outline the
glyphs, and PDF exports embed the font to preserve its appearance on other systems.
